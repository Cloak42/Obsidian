## Intro/Concept:
designing and making a simple analog distortion pedal for the guitar using diodes, capasitors, op amps and more

---
## Brainstorm Ideas
- a system/series of interchangeable pedals
- we will make a baseplate that handles the passthrough, and power needs of each pedal
	- the base plate will have multiple slots where different distortion circuits can be added
- distortion types
	- hard clipping 
	- soft clipping
---
## Time Line:
- [ ] build the base plate, so that it provides each slot with the necessary power and other inputs to operate
- [ ] make schematic for each type of distortion you want 
- [ ] make and test the schmatics on a breadboard
- [ ] turn into pcb and get manufactured
- [ ] 3d print a case to protect everything
